# Milou

Milou is a private, single-user personal assistant. It is used only by its owner
and is not offered to the public.

## Privacy policy

- Milou accesses the owner's Google Calendar only, in order to read, create and
  update the owner's own events.
- Calendar data is processed on the owner's private server. It is not sold,
  shared with third parties, or used for advertising.
- Only the minimum data needed for scheduling is stored. Access tokens are kept
  in files readable only by the server's administrator account.
- Access can be revoked at any time at https://myaccount.google.com/connections.
